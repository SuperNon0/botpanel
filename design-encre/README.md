# Kit de design « encre »

Le style de cinéthèque (thème sombre/clair, 5 couleurs d'accent, barre de
navigation flottante en verre flouté), prêt à être posé sur n'importe quel site.

- **Guide complet** : [`LISEZMOI.md`](LISEZMOI.md) (règles, couleurs, polices, briques, mode d'emploi).
- **Fichiers à brancher** : `polices.css` + `polices/`, `encre.css`, `encre.js`, `icones.svg`
  (ou `tailwind/encre-tailwind.css` pour un site Tailwind).
- **Voir en vrai** : `demo.html` (toutes les briques) et `modele.html` (squelette de site).
- **Outils pour tout refaire** (démo, captures, tests) : dossier `outils/` de la branche du kit (non copié dans BotPanel).

Télécharger le kit en ZIP : bouton vert **Code → Download ZIP** sur cette branche.

Cette branche ne contient que le kit : elle est séparée du code de cinéthèque
et ne modifie aucun site.
