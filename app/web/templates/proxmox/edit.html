▸ Placeholders Proxmox disponibles

Utilise ces placeholders dans le titre, le message ou la valeur des champs :

  • {px:vmid} — ID de la VM/CT
  • {px:hostname} — Nœud Proxmox (alias : {px:node})
  • {px:severity} — Severite (info / warning / error)
  • {px:title} — Titre de la notification Proxmox
  • {px:body} — Corps de la notification Proxmox
  • {px:type} — Type (LXC / QEMU)
  • {px:storage} — Stockage cible du backup
  • {px:duration} — Duree du backup (ex. "2m 34s")
  • {px:size} — Taille du backup (ex. "2.1 Go")

Exemple de titre : ✅ Backup VM {px:vmid} termine en {px:duration}

Exemple de message : Nœud : {px:hostname} · Taille : {px:size}
