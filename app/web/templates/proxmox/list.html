URL du webhook

Dans Proxmox : Datacenter → Notifications → Add → Webhook

  • URL : http://<IP_LXC>:8080/api/proxmox/backup
  • Method : POST
  • Header : Authorization: Bearer <PROXMOX_WEBHOOK_SECRET> (si defini dans .env)

Body template (a coller dans Proxmox)

{
  "severity": "{{ '{{' }} severity {{ '}}' }}",
  "title":    "{{ '{{' }} title {{ '}}' }}",
  "body":     "{{ '{{' }} message {{ '}}' }}",
  "hostname": "{{ '{{' }} hostname {{ '}}' }}"
}

Placeholders disponibles dans les templates

Utilise-les dans le titre, le message ou les champs :

  • {px:vmid} — ID de la VM/CT
  • {px:hostname} — Nœud Proxmox
  • {px:severity} — Severite (info / warning / error)
  • {px:title} — Titre de la notification Proxmox
  • {px:body} — Corps de la notification Proxmox
  • {px:type} — Type de la VM (LXC / QEMU)
  • {px:storage} — Stockage cible du backup
  • {px:duration} — Duree du backup (ex. "2m 34s")
  • {px:size} — Taille du backup (ex. "2.1 Go")

Types d'evenements

  • Tous — Declenche pour n'importe quelle notification Proxmox
  • Info (succes) — Backup reussi (severity = info)
  • Warning — Backup avec avertissement
  • Erreur — Backup echoue (severity = error)
