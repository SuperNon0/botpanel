Mot de passe oublié

Le mot de passe administrateur se réinitialise sur le serveur (accès shell), sans avoir besoin d'être connecté. Lance l'une de ces commandes :

Déploiement (LXC / VM)

sudo bash /opt/botpanel/deploy/reset_admin.sh

En local (dev)

python -m app.reset_admin

La commande définit le nouveau mot de passe, puis tu te reconnectes en local. (Redémarre le service ensuite.)
